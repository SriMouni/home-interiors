# 3 BHK Home Interiors — interactive 3D model

Live site: https://srimouni.github.io/home-interiors/

A furnished, walk-through 3D model of a 3 BHK flat (about 44 ft × 39 ft), built with three.js. Warm modern Indian interiors: cream, light oak, beige marble, brass, olive and terracotta.

## How to use
- **Overview:** drag to rotate, scroll or pinch to zoom, right-drag to pan.
- **Go inside:** tap a room button, double-click the floor, or click the mini-map (top right).
- **Inside a room:** drag to look around; ↑ ↓ walk, ← → move sideways, Q / E turn, + / − zoom. On-screen buttons do the same on phones.
- **Click any furniture** to see its size and materials and try other colours.
- **Design ideas:** each room's panel shows the reference images generated for it; click one to see it full screen.
- **Zoom:** scroll zooms toward the mouse pointer; the ＋ / － / ⌂ / Top buttons work too. Use **Zoom to it** on any selected furniture.
- **Tools:** guided tour of every room, measure tool (click two points), wall paint colours, reset colours.

## Updating
Replace `index.html` with the latest export and push — GitHub Pages republishes automatically.
